FrizzNet Framework Setup

A lightweight, connection-oriented Steam multiplayer framework for Unity 6+. Utilizing Steamworks.NET and Steam Networking Sockets for NAT-punching P2P gameplay.

🚀 Core Requirements
  • Unity 6+ (or modern LTS versions).
  • Steam Client running and logged into an active account.
  • Steamworks.NET package installed in your Unity project.
  • A steam_appid.txt file in your project root containing your AppID (default test AppID is 480).
⚙️ Fast Setup Steps
  1. Create a persistent GameObject in your starting scene named NetworkManager.
  2. Attach both the NetworkManager and SteamTransport scripts.
  3. Assign the SteamTransport reference to the Transport Component slot.
  4. Drag your player prefab (decorated with NetworkIdentity) into the Spawnable Prefabs registry list.
API Reference

NetworkManager

Manages player lists, replicates system events (spawn, destroy, transforms, voice), and routes custom developer packet handlers.

Properties & Methods
Method / Variable Type Description
Instance Static Getter Retrieve the active NetworkManager singleton instance.
IsHost bool True if this client is acting as the host/server.
IsClient bool True if this client is connected to a remote host.
RegisterHandler(id, callback) void Registers a custom packet reader callback for a specific message ID.
Spawn(prefab, pos, rot, ownerId) GameObject Instantiates a registered prefab across all connected clients (Host only).
Despawn(obj) void Destroys a networked GameObject across all clients (Host only).
💻 Code Example: Messaging
// Send data from Client to Server
using (MessageWriter writer = new MessageWriter())
{
    writer.WriteString("Custom message content!");
    NetworkManager.Instance.SendToServer(MyMessageId, writer, true);
}

// Receive and read incoming data
void Start()
{
    NetworkManager.Instance.RegisterHandler(MyMessageId, OnDataReceived);
}

void OnDataReceived(ulong senderId, MessageReader reader)
{
    string msgText = reader.ReadString();
    Debug.Log($"Received text: {msgText} from {senderId}");
}
API Reference

SteamTransport

P2P Transport implementation using raw Steam Networking Sockets. Manages listen sockets, remote socket handles, and matchmaking lobby lifecycle callbacks.

⚙️ Inspector Fields
Field Name Type Description
m_VirtualPort int (Default: 0) The virtual port channel assigned for Steam socket connections.
m_AutoConnectToLobbyOwner bool (Default: true) Auto-starts server listen sockets or client connection attempts on lobby status shifts.
Host Migration

FrizzNet transport hooks into lobby owner change callbacks. If the lobby owner leaves, Steam elects a new owner. If the local client is promoted, they automatically launch their hosting socket loop, and other clients reconnect to the new host without disconnecting from the lobby.

API Reference

NetworkIdentity

Identifies GameObjects uniquely across the network. Tracks connection credentials, local authority, and player association.

Properties
Property Type Description
NetworkId ulong Unique network ID mapped dynamically by the NetworkManager.
OwnerConnectionId ulong The SteamID64 of the client who owns and controls this object.
HasAuthority bool True if the local player has authority and writes updates to this object.
IsLocalPlayer bool True if this GameObject represents the local player's avatar.
💻 Code Example: Authority Check
void Update()
{
    // Block input and movements if the local player does not own this clone
    if (!GetComponent<NetworkIdentity>().HasAuthority) return;

    float inputY = Input.GetAxis("Vertical");
    transform.Translate(0, 0, inputY * Time.deltaTime * 4f);
}
API Reference

FrizzNetworkTransform

Replicates position and rotation variables. Compares movement thresholds and smoothly interpolates (lerps) remote positions to eliminate visual lag.

Tuning Properties
Field Default Description
m_SendRate 20 updates/sec Frequency of update dispatches sent by the authoritative owner.
m_PositionThreshold 0.01 units Minimum distance movement required to trigger a coordinate update packet.
m_RotationThreshold 0.5 degrees Minimum angular shift required to trigger a rotation update packet.
m_LerpSpeed 15.0 Velocity of the smoothing interpolation on remote clients.

FrizzVoiceManager

Enables real-time, spatialized or global voice chat using Steam's high-fidelity compression codecs. Automatically manages recording and speaker allocation.

Settings Configurations
Setting Variable Default Description
EnableVoice true Toggles the entire voice manager recording and processing loop.
UsePushToTalk true If true, microphone only records while holding the designated talk key.
PushToTalkKey KeyCode.V Keyboard key mapped to trigger Push-To-Talk capture.
SpatialAudio true Positions speaking voices relative to their matching player object in 3D space.
MaxAudioDistance 35.0 units The logarithmic rolloff cutoff distance for spatial voice sources.
Implementation Plans & Architecture

FrizzVoiceManager uses SteamUser.StartVoiceRecording to capture local mic input unmanaged. Compressed bytes are polled and sent unreliably to the server inside P2P sockets, which are routed to client speakers. Clients decode raw bytes back into PCM using SteamUser.DecompressVoice and feed a procedural circular AudioClip stream.

FrizzPlayerSpawner

Manages player character spawning across the network. Supports multiple spawn point selection modes (Random/RoundRobin), automated connection hooks, and spawn area collision/overlap checking.

Settings Configurations
Setting Variable Default Description
PlayerPrefab None (GameObject) The player prefab to spawn across the network. Must have a NetworkIdentity component.
SpawnPoints Empty List A list of Transforms representing valid spawn locations.
SpawnMode SpawnSelectionMode.Random How spawn points are chosen (Random vs. RoundRobin).
AutoSpawn true If true, automatically hooks client connection and lobby join events to spawn players.
AvoidOccupiedSpawnPoints true If true, checks if a spawn point is occupied by physics objects before placing a player.
OccupationCheckRadius 1.5 units The radius of the overlap checking sphere around the spawn point.
OccupiedLayerMask ~0 (Everything) The physics layers checked for obstacles when spawning.
💻 Code Example: Manual Spawning
// Turn off AutoSpawn in the inspector, then manage spawns in C#
public class CustomGameManager : MonoBehaviour
{
    [SerializeField] private FrizzPlayerSpawner m_Spawner;

    private void Start()
    {
        // Subscribe to game start event and manually spawn the host player
        if (NetworkManager.Instance.IsHost)
        {
            ulong mySteamId = SteamUser.GetSteamID().m_SteamID;
            m_Spawner.SpawnPlayer(mySteamId);
        }
    }
}
