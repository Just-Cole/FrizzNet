Production boundary

The host must validate client messages and owner-authored state. Late join, interest, lobby passwords, and host migration are limited. Each section states the exact behavior.

Getting started

Setup

One persistent manager, one transport, matching spawnable prefabs on every peer.

Install

Add FrizzNet from Git: https://github.com/Just-Cole/FrizzNet.git. Steamworks.NET is installed automatically. You do not add it by hand.

Requirements: Unity 6+, a running Steam client for player builds, and a Steam App ID. Development uses 480 (SpaceWar).

Shared player setup

1

Create a startup GameObject. Add SteamManager and NetworkManager.

2

Add SteamTransport on the same object and assign it to Transport Component.

3

Register every networked prefab (with NetworkIdentity) in Spawnable Prefabs.

4

Optionally add FrizzServerManager, FrizzVoiceManager, and FrizzNetworkSceneManager.

5

Keep a project-root steam_appid.txt. SteamManager writes 480 there in the Editor. It never writes into the Unity Editor install folder.

Editor Play Mode

SteamManager uses SteamAPI.InitEx and then InitRelayNetworkAccess. It does not call RestartAppIfNecessary, so Play Mode will not quit the Editor. Change the App ID before shipping.

Architecture

Listen host vs dedicated

Pick one authority process. Do not mix the two transports on the same GameObject.

Listen host

  • SteamManager + SteamTransport
  • A player is the host
  • Steam lobby for matchmaking and invites
  • IsHost true, IsDedicatedServer false
  • LocalConnectionId is the host Steam user
  • Host migration can move the lobby owner

Dedicated Game Server

  • SteamGameServerManager + SteamGameServerTransport
  • No Steam user, no player pawn
  • Steam Game Server browser, not player lobbies
  • IsHost true and IsDedicatedServer true
  • LocalConnectionId is the game server Steam ID
  • Host does not migrate onto a connected player
Clients stay on SteamTransport

Players always initialize SteamManager and connect with SteamTransport.StartClient to a Steam ID64. Dedicated boxes never call SteamAPI.Init.

using FrizzNet.Core;

    [SerializeField] private string _lobbyName = "Co-op Session";

    {
        if (FrizzServerManager.Instance == null)

        FrizzServerManager.Instance.MaxPlayers = _maxPlayers;
        FrizzServerManager.Instance.LobbyName = _lobbyName;
        FrizzServerManager.Instance.LobbyPassword = _lobbyPassword;
        FrizzServerManager.Instance.LobbyType = ELobbyType.k_ELobbyTypePublic;
        FrizzServerManager.Instance.StartServer();
    }
}

using System.Collections.Generic;
using FrizzNet.Core;

public sealed class LobbyReadyExample : MonoBehaviour
{
    private void OnEnable()
    {
        FrizzLobby.OnLobbyDataUpdatedEvent += HandleLobbyDataUpdated;
    }

    private void OnDisable()
    {
        FrizzLobby.OnLobbyDataUpdatedEvent -= HandleLobbyDataUpdated;
    }

    public void SetReady(bool ready)
    {
        FrizzLobby.SetReadyState(ready);
    }

    public void InviteFriends()
    {
        FrizzLobby.InviteFriends();
    }

    private void HandleLobbyDataUpdated(CSteamID lobbyId, CSteamID memberId)
    {
        if (NetworkManager.Instance == null || !NetworkManager.Instance.IsHost)
            return;

        if (members.Count == 0)
            return;

        for (int i = 0; i < members.Count; i++)
        {
            if (!FrizzLobby.IsMemberReady(members[i]))
                return;
        }

        FrizzNetworkSceneManager.Instance.LoadScene("GameScene");
    }

Messaging

Chat relay

Listen-host is not a client. The host broadcasts locally. Remote clients send to the host, which validates and relays.

using FrizzNet.Core;
using FrizzNet.Messaging;
using UnityEngine;

public sealed class NetworkChat : MonoBehaviour
{
    private const short ChatId = 101;

    private void OnEnable()
    {
        NetworkManager.Instance.RegisterHandler(ChatId, HandleChat);
    }

    private void OnDisable()
    {
        if (NetworkManager.Instance != null)
            NetworkManager.Instance.UnregisterHandler(ChatId);
    }

    public void Send(string text)
    {
        if (NetworkManager.Instance == null || string.IsNullOrWhiteSpace(text))
            return;

        if (text.Length > 256)
            text = text.Substring(0, 256);

        using (MessageWriter writer = new MessageWriter())
        {
            writer.WriteString(text);

            if (NetworkManager.Instance.IsHost)
            {
                HandleLocal(NetworkManager.LocalConnectionId, text);
                NetworkManager.Instance.SendToAll(ChatId, writer, true);
            }
            else if (NetworkManager.Instance.IsClient)
            {
                NetworkManager.Instance.SendToServer(ChatId, writer, true);
            }
        }
    }

    private void HandleChat(ulong senderId, MessageReader reader)
    {
        string text = reader.ReadString();
        if (string.IsNullOrWhiteSpace(text) || text.Length > 256)
            return;

        if (NetworkManager.Instance.IsHost)
        {
            using (MessageWriter writer = new MessageWriter())
            {
                writer.WriteString(text);
                foreach (ulong clientId in NetworkManager.Instance.ConnectedClients)
                {
                    if (clientId != senderId)
                        NetworkManager.Instance.SendToClient(clientId, ChatId, writer, true);
                }
            }
        }

        HandleLocal(senderId, text);
    }

    private void HandleLocal(ulong authorId, string text)
    {
        Debug.Log("[" + authorId + "] " + text);
    }
}

Write and read every supported field

using FrizzNet.Core;
using FrizzNet.Messaging;
using UnityEngine;

public sealed class TypedPayloadExample : MonoBehaviour
{
    private const short PayloadId = 110;

    private void OnEnable()
    {
        NetworkManager.Instance.RegisterHandler(PayloadId, HandlePayload);
    }

    private void OnDisable()
    {
        if (NetworkManager.Instance != null)
            NetworkManager.Instance.UnregisterHandler(PayloadId);
    }

    public void SendSample(Vector3 point)
    {
        using (MessageWriter writer = new MessageWriter())
        {
            writer.WriteShort(1);
            writer.WriteInt(42);
            writer.WriteLong(1001L);
            writer.WriteFloat(1.5f);
            writer.WriteDouble(2.25);
            writer.WriteBool(true);
            writer.WriteString("crate");
            writer.WriteFloat(point.x);
            writer.WriteFloat(point.y);
            writer.WriteFloat(point.z);
            writer.WriteBytes(new byte[] { 1, 2, 3 });

            if (NetworkManager.Instance.IsHost)
                NetworkManager.Instance.SendToAll(PayloadId, writer, true);
            else if (NetworkManager.Instance.IsClient)
                NetworkManager.Instance.SendToServer(PayloadId, writer, true);
        }
    }

    private void HandlePayload(ulong senderId, MessageReader reader)
    {
        short kind = reader.ReadShort();
        int count = reader.ReadInt();
        long stamp = reader.ReadLong();
        float speed = reader.ReadFloat();
        double duration = reader.ReadDouble();
        bool grounded = reader.ReadBool();
        string id = reader.ReadString();
        Vector3 point = new Vector3(reader.ReadFloat(), reader.ReadFloat(), reader.ReadFloat());
        byte[] extra = reader.ReadBytes();
        Debug.Log(senderId + " " + kind + " " + id + " " + point);
    }
}

Spawn packets restore prefab, ID, pose, and owner only. Send variables and game state yourself.

using FrizzNet.Core;
using FrizzNet.Messaging;
using UnityEngine;

public sealed class LateJoinSnapshot : MonoBehaviour
{
    private const short SnapshotId = 120;

    [SerializeField] private int _roundNumber;

    private void OnEnable()
    {
        NetworkManager.OnClientConnected += HandleClientConnected;
        NetworkManager.Instance.RegisterHandler(SnapshotId, HandleSnapshot);
    }

    private void OnDisable()
    {
        NetworkManager.OnClientConnected -= HandleClientConnected;
        if (NetworkManager.Instance != null)

    {

            writer.WriteInt(NetworkManager.Instance.ConnectedClients.Count);
            NetworkManager.Instance.SendToClient(clientId, SnapshotId, writer, true);
        }
    }

    private void HandleSnapshot(ulong senderId, MessageReader reader)
    {
        _roundNumber = reader.ReadInt();
        int players = reader.ReadInt();
        Debug.Log("Late join round " + _roundNumber + " players " + players);
    }

                _bodyRenderers[i].enabled = false;
        }
    }

    public override void OnNetworkDespawn()
    {
        if (_controller != null)
            _controller.enabled = false;
    }
}

using FrizzNet.Core;
using UnityEngine;

public sealed class NetworkHealth : NetworkBehaviour
{
    private const short HealthSyncId = 1;
    private readonly FrizzNetworkVariable<int> _health = new FrizzNetworkVariable<int>(100);

    public int Health => _health.Value;

    public override void OnNetworkSpawn()
    {
        RegisterSyncVar(HealthSyncId, _health);
        _health.OnValueChanged += HandleHealthChanged;
    }

    public override void OnNetworkDespawn()
    {
        _health.OnValueChanged -= HandleHealthChanged;

    {
        if (!IsServer || amount <= 0)
            return;

        _health.Value = Mathf.Max(0, _health.Value - amount);
    }

    {
        Debug.Log("Health " + previous + " -> " + current);
    }
}

Server RPC and client RPC

Keep RPC handlers on the first NetworkBehaviour on the object. Call RegisterRpcHandlers from OnNetworkSpawn.

using FrizzNet.Core;
using FrizzNet.Messaging;
using UnityEngine;

public sealed class NetworkScore : NetworkBehaviour
{
    private const short AddScoreRpc = 1;
    private const short ScoreChangedRpc = 2;
    private int _score;

    public override void OnNetworkSpawn()
    {
        RegisterRpcHandlers();
    }

    public void RequestScore(int amount)
    {
        if (!HasAuthority || amount <= 0)
            return;

        using (MessageWriter writer = new MessageWriter())
        {
            writer.WriteInt(amount);
            SendServerRpc(AddScoreRpc, writer);
        }
    }

    [FrizzRpc(AddScoreRpc, FrizzRpcTarget.Server)]
    private void HandleAddScore(int amount)
    {
        if (!IsServer || amount <= 0 || amount > 100)
            return;

        _score += amount;

        using (MessageWriter writer = new MessageWriter())
        {
            writer.WriteInt(_score);
            SendClientRpc(ScoreChangedRpc, writer);
        }
    }

    [FrizzRpc(ScoreChangedRpc, FrizzRpcTarget.AllClients)]
    private void HandleScoreChanged(int score)
    {
        _score = score;
        Debug.Log("Score " + _score);
    }
}

Client interact request, host validates

using FrizzNet.Core;
using FrizzNet.Messaging;
using UnityEngine;

public sealed class WorldInteract : MonoBehaviour
{
    private const short InteractId = 130;
    [SerializeField] private float _maxDistance = 3f;

    private void OnEnable()
    {
        NetworkManager.Instance.RegisterHandler(InteractId, HandleInteract);
    }

    private void OnDisable()
    {
        if (NetworkManager.Instance != null)
            NetworkManager.Instance.UnregisterHandler(InteractId);
    }

    public void RequestOpen(ulong chestNetworkId)
    {
        if (NetworkManager.Instance == null)
            return;

        using (MessageWriter writer = new MessageWriter())
        {
            writer.WriteLong((long)chestNetworkId);

            if (NetworkManager.Instance.IsHost)
                TryOpen(NetworkManager.LocalConnectionId, chestNetworkId);
            else if (NetworkManager.Instance.IsClient)
                NetworkManager.Instance.SendToServer(InteractId, writer, true);
        }
    }

    private void HandleInteract(ulong senderId, MessageReader reader)
    {
        if (!NetworkManager.Instance.IsHost)
            return;

        ulong chestId = (ulong)reader.ReadLong();
        TryOpen(senderId, chestId);
    }

    private void TryOpen(ulong senderId, ulong chestId)
    {
        if (!NetworkManager.Instance.NetworkObjects.TryGetValue(chestId, out NetworkIdentity chest))
            return;

        NetworkIdentity pawn = FindOwnedPawn(senderId);
        if (pawn == null)
            return;

        float distance = Vector3.Distance(pawn.transform.position, chest.transform.position);
        if (distance > _maxDistance)
            return;

        Debug.Log("Opened chest " + chestId + " for " + senderId);
    }

    private static NetworkIdentity FindOwnedPawn(ulong ownerId)
    {
        foreach (NetworkIdentity identity in NetworkManager.Instance.NetworkObjects.Values)
        {
            if (identity != null && identity.OwnerConnectionId == ownerId)
                return identity;
        }

        return null;
    }
}

Dedicated

Dedicated Game Server bootstrap

Do not put SteamManager or SteamTransport on this process. Wait for LoggedOn before StartHost.

using FrizzNet.Core;
using FrizzNet.Steam;
using UnityEngine;

public sealed class DedicatedHostExample : MonoBehaviour
{
    [SerializeField] private SteamGameServerManager _gameServer;
    [SerializeField] private int _maxPlayers = 8;

    private void OnEnable()
    {
        SteamGameServerManager.LoggedOnChanged += HandleLoggedOn;
    }

    private void OnDisable()
    {
        SteamGameServerManager.LoggedOnChanged -= HandleLoggedOn;
    }

    public void StartDedicated()
    {
        if (NetworkManager.Instance == null || _gameServer == null)
            return;

        NetworkManager.Instance.SetDedicatedServer(true);
        _gameServer.ApplySettings("FrizzNet Dedicated", _maxPlayers, "game=frizznet", 27015, 27016);
        _gameServer.Initialize();
    }

    private void HandleLoggedOn(bool loggedOn)
    {
        if (!loggedOn || NetworkManager.Instance == null || NetworkManager.Instance.Transport == null)
            return;

        NetworkManager.Instance.Transport.StartHost(_maxPlayers);
        SteamGameServerManager.SetAdvertisedPlayers(0, _maxPlayers);
    }
}

using FrizzNet.Core;
using UnityEngine;

public sealed class HostSpawnExample : MonoBehaviour
{
    [SerializeField] private GameObject _prefab;
    private GameObject _instance;

    public void SpawnForClient(ulong ownerConnectionId)
    {
        if (NetworkManager.Instance == null || !NetworkManager.Instance.IsHost)
            return;

        NetworkIdentity identity = _prefab.GetComponent<NetworkIdentity>();
        if (identity != null)
            NetworkManager.Instance.RegisterSpawnablePrefab(identity);

        _instance = NetworkManager.Instance.Spawn(
            _prefab,
            transform.position,
            transform.rotation,
            ownerConnectionId);
    }

    public void Despawn()
    {
        if (_instance != null && NetworkManager.Instance != null && NetworkManager.Instance.IsHost)
        {
            NetworkManager.Instance.Despawn(_instance);
            _instance = null;
        }
    }

    public bool TryGet(ulong networkId, out NetworkIdentity identity)
    {
        identity = null;
        return NetworkManager.Instance != null
            && NetworkManager.Instance.NetworkObjects.TryGetValue(networkId, out identity);
    }
}

    [SerializeField] private FrizzNetworkTransform _networkTransform;
    [SerializeField] private float _speed = 4.2f;
    private Vector2 _move;

    public void SetMove(Vector2 move)
    {
        _move = move;
    }

    private void Update()
    {
        if (!HasAuthority || _controller == null || !_controller.enabled)
            return;

        Vector3 planar = new Vector3(_move.x, 0f, _move.y);
        if (planar.sqrMagnitude > 1f)
            planar.Normalize();

        _controller.Move(planar * _speed * Time.deltaTime);
    }

    public void SnapAndBroadcast(Vector3 position)
    {
        transform.position = position;
        if (_networkTransform != null)
            _networkTransform.ForceBroadcastState();
    }
}

Architecture

Authority

The host owns session flow and object lifetime. Game code owns validation. Dedicated processes are hosts with no pawn.

Framework-enforced

  • Host-only spawn and despawn
  • Host-only network scene initiation
  • Local authority flags from object ownership
  • Dedicated hosts skip local player spawn

You must validate

  • Sender ownership and permissions
  • Movement, physics, cooldowns, inventory, and damage
  • Payload length, range, frequency, and session phase
  • Admission, kicking, and reconnect policy
Do not trust client payload identity

Use the handler senderId. Client RPCs, variable writes, and sync packets are not an anti-cheat boundary.

Core API

Messaging

Managed binary serialization routed by a signed 16-bit message ID.

Rules

  • Use positive IDs for game messages. Negative IDs are reserved.
  • Read fields in the same order they were written.
  • Dispose readers and writers.
  • Unregister handlers when their owner disables.
  • Validate before relaying.
using (MessageWriter writer = new MessageWriter())
{
    writer.WriteInt(slot);
    writer.WriteFloat(yaw);
    writer.WriteBool(sprinting);
    writer.WriteString(itemId);
    writer.WriteFloat(point.x);
    writer.WriteFloat(point.y);
    writer.WriteFloat(point.z);
    writer.WriteBytes(payload);

    if (NetworkManager.Instance.IsHost)
        NetworkManager.Instance.SendToAll(ItemUsedId, writer, true);
    else if (NetworkManager.Instance.IsClient)
        NetworkManager.Instance.SendToServer(ItemUsedId, writer, true);
}

int slot = reader.ReadInt();
float yaw = reader.ReadFloat();
bool sprinting = reader.ReadBool();
string itemId = reader.ReadString();
Vector3 point = new Vector3(reader.ReadFloat(), reader.ReadFloat(), reader.ReadFloat());
byte[] payload = reader.ReadBytes();
State API

RPCs & Network Variables

Reliable typed calls and delta replication for supported primitive state.

RPCs

Call RegisterRpcHandlers() from OnNetworkSpawn. Supported parameters: int, float, bool, string, long, ulong, Vector3, and Quaternion.

using FrizzNet.Core;
using FrizzNet.Messaging;

public sealed class NetworkScore : NetworkBehaviour
{
    private const short AddScoreRpc = 1;
    private int _score;

    public override void OnNetworkSpawn()
    {
        RegisterRpcHandlers();
    }

    public void RequestScore(int amount)
    {
        if (!HasAuthority || amount <= 0)
            return;

        using (MessageWriter writer = new MessageWriter())
        {
            writer.WriteInt(amount);
            SendServerRpc(AddScoreRpc, writer);
        }
    }

    [FrizzRpc(AddScoreRpc, FrizzRpcTarget.Server)]
    private void HandleAddScore(int amount)
    {
        if (IsServer && amount > 0 && amount <= 100)
            _score += amount;
    }
}

FrizzNetworkVariable<T>

Register each variable with a stable sync ID. Supported values: int, float, bool, string, long, ulong, and Vector3.

Current dispatch limits

RPC packets dispatch to the first NetworkBehaviour on an object. Variable and RPC client writes need host-side validation. Neither system supplies current values to late joiners.

Transport

SteamTransport

Steam Networking Sockets P2P for listen hosts and for every player client.

Inspector

Virtual Port selects the Steam socket channel. Auto Connect To Lobby Owner starts hosting for the lobby owner and connects other members.

Client join

StartClient takes a Steam ID64 string. That can be a lobby owner or a dedicated game server ID from FrizzGameServerBrowser.

NetworkManager.Instance.Transport.StartClient(steamId64);
NetworkManager.Instance.Transport.Disconnect();
Capacity and admission

The transport does not fully enforce lobby membership or capacity on every incoming socket. Validate admission in session code. Connectivity migration does not restore gameplay state.

Dedicated

Steam Game Server

SteamGameServerManager initializes the Steam Game Server API. It never uses SteamUser, SteamAPI.Init, or RestartAppIfNecessary.

Dedicated process setup

1

Add NetworkManager, set IsDedicatedServer true.

2

Add SteamGameServerManager and SteamGameServerTransport. Assign the transport.

3

Call Initialize(), or enable Auto Initialize. Wait for LoggedOn.

4

Start the host with SteamGameServerTransport.StartHost.

5

Ship Steamworks Game Server DLLs, a root steam_appid.txt, and outbound Steam traffic. SpaceWar uses anonymous logon until you have a real App ID and GSLT.

Advertise

Inspector fields: bind IP, game port 27015, query port 27016, server name, max players, game tags, product, mod dir, map, and version. SpaceWar product must be Spacewar.

After logon the manager advertises the server and calls InitRelayNetworkAccess. Update player counts with SteamGameServerManager.SetAdvertisedPlayers.

using FrizzNet.Core;
using FrizzNet.Steam;

NetworkManager.Instance.IsDedicatedServer = true;

SteamGameServerManager manager = FindAnyObjectByType<SteamGameServerManager>();
manager.ApplySettings("FrizzNet Dedicated", 8, "game=frizznet", 27015, 27016);
manager.Initialize();

SteamGameServerManager.LoggedOnChanged += loggedOn =>
{
    if (loggedOn)
        NetworkManager.Instance.Transport.StartHost(8);
};

Transport contract

INetworkTransport

Implemented by SteamTransport and SteamGameServerTransport.

Responsibilities

Role state, host/client startup and shutdown, per-client connections, send operations, disconnect operations, event polling, and connection/data events.

Custom transport

Raise callbacks on Unity's main thread, assign stable connection IDs, preserve message boundaries, and honor the supplied payload size.

Synchronizer

FrizzNetworkTransform

Owner-authored position, rotation, optional scale, thresholds, send rate, and interpolation.

The authority peer sends. Remotes interpolate. Updates are unreliable and replaceable. Use ForceBroadcastState() for an immediate sample.

if (HasAuthority)
    _networkTransform.ForceBroadcastState();
Authority

The host relays client transform packets without complete ownership or movement validation. Validate sensitive movement separately.

Synchronizer

FrizzNetworkAnimator

Tracks float, int, and bool parameters and replicates triggers.

Call SetTrigger on FrizzNetworkAnimator, not directly on the Animator, when the trigger must replicate.

_networkAnimator.TargetAnimator = childAnimator;
if (HasAuthority)
    _networkAnimator.SetTrigger("Jump");
Scope

Animator states, transitions, layer time, and late-join snapshots are not serialized.

Synchronizer

FrizzNetworkRigidbody

Replicates position and linear velocity for physics-driven objects.

Configure remote physics

Rotation and angular velocity are not synchronized, and remote bodies are not automatically kinematic. Prevent local simulation from fighting interpolation.

Bandwidth

FrizzInterestManager

Optional distance filtering for host relays of client-authored transform updates.

Configure InterestRadius and InterestEnabled. Owners remain interested. Unknown client positions default to interested.

FrizzInterestManager.Instance.InterestEnabled = true;
FrizzInterestManager.Instance.InterestRadius = 50f;
Narrow scope

It does not filter host transforms, voice, spawn, Animator, Rigidbody, RPC, variable, or custom traffic.

Security

Password and kick are convenience controls, not secure admission or banning.

FrizzHostMigration

Object snapshot support over Steam lobby-owner reconnection. Listen-host only.

Captured

Not captured
